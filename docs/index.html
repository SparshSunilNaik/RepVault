      05 / Under the hood

      Built to stay put

      MVVM in Kotlin: Compose screens talk to ViewModels, which go through one repository to Room. No account, no server, no network permission needed.

      Layers

      Three tables

      exercisesidnamemuscleGroup
      workout_sessionsiddateworkoutType
      workout_setsidsessionIdexerciseIdweightreps

      Sets reference both a session and an exercise, with cascading deletes and an index on each key. The first-launch name prompt lives in DataStore, and backups are the three tables as JSON through Gson.

      06 / Build it

      On your phone

      Needs a JDK and the Android SDK, or just Android Studio. Minimum Android 8.0 (API 26), targets API 36.

      macOS or Linux

      git clone https://github.com/SparshSunilNaik/RepVault.git
cd RepVault
./gradlew assembleDebug

      The APK lands in app/build/outputs/apk/debug/.

      Windows

      git clone https://github.com/SparshSunilNaik/RepVault.git
cd RepVault
.\gradlew.bat assembleDebug

      With a phone connected and USB debugging on, installDebug builds and installs in one go.
